# Project 024 — Tideglass Vows

An immersive coastal-dawn wedding story built with React, Vite and GSAP.

## Story concept
A ceremony told like the tide going out: first light, quiet shore, portrait-through-glass, salt notes, a continuous photographic tide ribbon, low-tide breathing space, tide-pool details, ceremony line, family contact frames, a coral sunrise shift, final portrait and archive.

## Design DNA
- Emotional metaphor: tide / memory / return.
- Palette: sea-glass teal, salt white, wet sand, oxidized silver, sunrise coral.
- Typography: Newsreader editorial serif + Archivo Black finale + DM Mono documentary metadata.
- Composition: horizon split, porthole camera, postcard stack, pinned tide ribbon, circular tide-pool photography, contact-sheet mosaic, coral color transformation.
- Signature entrance: translucent water pane / receding-tide gate.
- Signature interaction: pinned photographic tide ribbon plus circular porthole camera expansion.
- Mobile: vertical editorial stacks, touch-safe scroll interactions, large portrait crops, reduced-motion fallback.
